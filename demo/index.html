appear-on-scroll v2

Elements that arrive with the scroll.

IntersectionObserver-based reveals with a scroll-direction-aware slide: scroll down and things rise into place, scroll back up and they settle down from above. Zero dependencies.

Scroll down for each animation, then scroll back up to see them arrive the other way.

The signature

Direction-aware slide

animation: 'slide' with direction: 'auto' (the defaults). These cards slide up into place as you scroll down, and slide down into place when you scroll back up to them. No scroll listener involved — the observer entry tells us which edge each element crossed.

Watch me twice

Pass me going down, then come back up. I arrive from whichever side you approached.

Same batch

Everything in a section follows the same scroll direction.

Pinned directions

direction: up · down · left · right

Set an explicit direction and the slide ignores scroll direction entirely.

up

down

Zoom

Blur

Blur

Stagger

Stagger grid

stagger: 90 — elements arriving together each wait 90ms longer than the one before, so a grid cascades instead of popping in at once. The wave is measured in time rather than in observer batches, so the cascade looks the same however fast you scrolled into it.

Replay

once: false vs once: true

By default elements hide again when they leave the viewport and replay on re-entry. With once: true the first appearance sticks.

once: false

Scroll away and back — I replay every time.

once: true

I appear once and never hide again.
